Visor BC3 — E3G BIM Tools

Carrega un fitxer .bc3 (FIEBDC-3) generat per l'add-in i visualitza les partides amb les seves mediciones agrupades per sistema MEP + nivell.

El fitxer es processa al teu navegador — res no s'envia a cap servidor.

Com s'agrupen les línies: el motor d'exportació posa un prefix [Sistema · Nivell] a cada línia de medició (p. ex. [SAN-Fecals B-01 · Planta 1] Pipe B01-1). Aquest visor parsa aquest prefix per agrupar visualment. TCQ/Presto les ordenen alfabèticament i les mostren juntes. En el futur, el criteri d'agrupació serà configurable des de l'app.
